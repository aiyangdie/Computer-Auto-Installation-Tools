# 软件下载与安装管理器 - 使用说明

## 简介

软件下载与安装管理器是一个综合性工具，用于自动化软件的下载和安装过程。它能够自动检测操作系统类型，从网络下载适合当前系统的软件安装包，并执行静默安装，大大简化了软件部署的过程。

## 系统要求

- Python 3.6 或更高版本
- 支持的操作系统：Windows、macOS、Linux
- 必要的Python库：
  - requests：用于网络请求和下载
  - tqdm：用于显示进度条
  - beautifulsoup4：用于网页解析（某些下载源需要）

## 安装依赖

在使用本工具前，请确保已安装所有依赖库：

```
pip install requests tqdm beautifulsoup4
```

## 目录结构

使用前，请确保程序目录结构如下：

```
软件下载与安装管理器/
├── auto_software_installer.py    # 主程序
├── default_config.json           # 默认配置文件
├── downloads/                    # 下载目录（自动创建）
└── software_installer.log        # 日志文件（自动创建）
```

## 快速开始

### 基本使用

1. 直接运行主程序：

```
python auto_software_installer.py
```

程序会读取`default_config.json`中的配置，下载并安装所有启用的软件。

### 指定配置文件

```
python auto_software_installer.py -c my_config.json
```

使用自定义的配置文件替代默认配置。

### 列出可用软件

```
python auto_software_installer.py -l
```

列出程序支持的所有软件。

### 安装特定软件

```
python auto_software_installer.py -i chrome,vscode,python
```

只安装指定的软件，以逗号分隔多个软件名称。

## 配置文件说明

配置文件使用JSON格式，包含以下主要设置：

```json
{
    "download_dir": "downloads",
    "install_dir": null,
    "max_workers": 4,
    "software_list": [
        {
            "name": "chrome",
            "enabled": true
        },
        {
            "name": "python",
            "enabled": true
        },
        {
            "name": "vscode",
            "enabled": true
        },
        {
            "name": "notepadpp",
            "enabled": true
        }
    ]
}
```

### 配置项说明

- **download_dir**：下载文件的存储目录，相对于程序所在目录
- **install_dir**：安装目录，如果为null则使用默认安装路径
- **max_workers**：最大并发下载/安装数量
- **software_list**：要安装的软件列表
  - **name**：软件名称，必须是程序支持的软件之一
  - **enabled**：是否启用，设为false可以暂时禁用某个软件的安装

### 自定义配置示例

以下是一个自定义配置的示例，用于在特定目录安装开发工具：

## 命令行参数

程序支持以下命令行参数：

```
-c, --config      指定配置文件路径，默认为default_config.json
-l, --list        列出所有可用的软件
-i, --install     指定要安装的软件，以逗号分隔
-h, --help        显示帮助信息
```

## 日志系统

所有操作都会记录在`software_installer.log`文件中，同时也会在控制台显示。日志包含以下信息：

- 操作系统检测结果
- 配置加载信息
- 下载进度和结果
- 安装过程和结果
- 错误和异常信息

## 高级用法

### 添加新软件

如果需要添加新的软件支持，可以在`SoftwareDefinitions`类中添加新的方法：

```python
@staticmethod
def get_new_software(system_info):
    """获取新软件的下载信息"""
    if system_info["system"] == "windows":
        url = "https://example.com/download/software_windows.exe"
        install_cmd = ["software_windows.exe", "/S"]
        return {"url": url, "install_cmd": install_cmd}
    elif system_info["system"] == "darwin":  # macOS
        url = "https://example.com/download/software_mac.dmg"
        install_cmd = ["hdiutil", "attach", "software_mac.dmg"]
        return {"url": url, "install_cmd": install_cmd}
    elif system_info["system"] == "linux":
        return {"url": None, "install_cmd": ["apt", "install", "software", "-y"]}
    return None
```

然后在`get_software_info`方法中添加映射：

```python
methods = {
    # 现有软件...
    "new_software": SoftwareDefinitions.get_new_software,
}
```

### 使用代理

如果需要通过代理下载，可以设置环境变量：

```
# Windows
set HTTP_PROXY=http://proxy.example.com:8080
set HTTPS_PROXY=http://proxy.example.com:8080

# Linux/macOS
export HTTP_PROXY=http://proxy.example.com:8080
export HTTPS_PROXY=http://proxy.example.com:8080
```

### 批处理模式

可以创建批处理脚本或shell脚本来自动化安装过程：

**Windows (install_dev_tools.bat):**
```batch
@echo off
python auto_software_installer.py -i python,vscode,git,nodejs
```

**Linux/macOS (install_dev_tools.sh):**
```bash
#!/bin/bash
python3 auto_software_installer.py -i python,vscode,git,nodejs
```

## 常见问题

### 1. 下载失败

**问题**：软件下载失败，日志显示网络错误。

**解决方案**：
- 检查网络连接
- 确认下载URL是否有效
- 尝试使用代理
- 手动下载文件并放在downloads目录中

### 2. 安装失败

**问题**：软件下载成功但安装失败。

**解决方案**：
- 检查日志文件了解具体错误
- 确认是否有足够的权限（可能需要管理员权限）
- 检查安装命令是否正确
- 尝试手动运行安装程序

### 3. 不支持的操作系统

**问题**：程序无法识别当前操作系统。

**解决方案**：
- 检查系统是否为支持的操作系统（Windows、macOS、Linux）
- 如果是支持的系统但无法识别，请提交问题报告

### 4. 配置文件错误

**问题**：程序报告配置文件错误。

**解决方案**：
- 确保配置文件是有效的JSON格式
- 检查必要的字段是否存在
- 尝试使用默认配置文件作为模板

## 安全注意事项

- 始终从可信来源下载软件
- 定期更新软件定义以获取最新的下载链接
- 注意某些安装可能需要管理员权限
- 在运行批量安装前，建议先检查配置文件中的软件列表
