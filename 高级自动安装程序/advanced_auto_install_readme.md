# 高级自动安装程序

这个Python脚本提供了一个高级的自动安装工具，可以帮助你批量安装电脑软件，支持GUI界面和命令行两种模式。

## 功能特点

- **双模式操作**：图形界面(GUI)和命令行(CLI)两种使用方式
- **智能安装**：自动尝试多种静默安装参数，适配不同类型的安装包
- **自定义过滤**：根据文件名、大小等条件筛选安装包
- **特殊程序支持**：针对常见软件（如Python、Git、NVIDIA驱动等）提供特定的安装参数
- **交互式选项**：支持静默安装和交互式安装两种模式
- **详细日志**：记录安装过程，方便排查问题
- **安装结果可视化**：在GUI中直观显示安装成功或失败状态

## 系统要求

- Python 3.6+
- Windows操作系统
- tkinter库（GUI模式需要）

## 使用方法

### GUI模式

1. 直接运行脚本（不带参数）：`python advanced_auto_install.py`
2. 在界面中选择根目录（默认为脚本所在目录）
3. 设置过滤条件（可选）
4. 从列表中选择要安装的程序
5. 点击"安装选中项"按钮开始安装

### 命令行模式

使用以下参数运行脚本：

```
python advanced_auto_install.py [参数]
```

可用参数：
- `-d, --directory`：指定根目录，默认为脚本所在目录
- `-s, --subfolders`：包含子文件夹中的exe文件
- `-f, --filter`：文件名过滤，支持正则表达式
- `--min-size`：最小文件大小(MB)
- `--max-size`：最大文件大小(MB)
- `-t, --timeout`：安装超时时间(秒)，默认300秒
- `-i, --interactive`：使用交互模式安装，而非静默安装

示例：
```
# 安装所有小于100MB的exe文件
python advanced_auto_install.py --max-size 100

# 只安装包含"chrome"的exe文件，使用交互模式
python advanced_auto_install.py -f chrome -i

# 从指定目录安装，包含子文件夹
python advanced_auto_install.py -d "D:\下载" -s
```

## 界面说明

GUI界面包含以下主要部分：

1. **顶部区域**：设置根目录和刷新按钮
2. **过滤选项区**：设置名称过滤、大小范围、子文件夹选项等
3. **程序列表**：显示找到的安装程序及其大小
4. **操作按钮**：安装选中项、查看日志和退出

## 注意事项

- 建议以管理员身份运行此脚本，以确保有足够的权限安装程序
- 静默安装可能不适用于所有程序，有些程序可能仍需手动操作
- 交互式安装模式下，程序会启动安装向导但不会等待其完成
- 安装大型程序时，可能需要增加超时时间
- 安装过程中请勿关闭程序窗口
- 安装结果颜色标识：绿色=成功，红色=失败，灰色=待安装
