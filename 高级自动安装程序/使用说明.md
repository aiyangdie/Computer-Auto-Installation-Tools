# 高级自动安装程序 - 使用说明

## 简介

高级自动安装程序是一个功能强大的自动化软件安装工具，支持图形界面和命令行两种操作模式。它能够自动查找安装文件，应用各种过滤条件，并尝试多种静默安装参数，大大简化了软件批量安装的过程。

## 系统要求

- Python 3.6 或更高版本
- Windows操作系统
- 图形界面模式需要tkinter库（Python标准库，通常随Python一起安装）

## 目录结构

使用前，请确保程序目录结构如下：

```
高级自动安装程序/
├── advanced_auto_install.py    # 主程序
├── auto_install.py             # 简化版程序
├── exe/                        # 存放安装文件的目录
│   ├── software1.exe
│   ├── software2.exe
│   └── ...
└── install_logs/               # 安装日志目录（自动创建）
```

## 快速开始

### 图形界面模式

1. 双击运行`advanced_auto_install.py`，或在命令行中执行：
   ```
   python advanced_auto_install.py
   ```

2. 程序会启动图形界面，默认查找当前目录下的`exe`文件夹中的安装文件。

3. 使用界面上的控件设置过滤条件、浏览目录等。

4. 点击"刷新"按钮查看符合条件的安装文件。

5. 选择要安装的文件，然后点击"安装选中项"按钮开始安装。

### 命令行模式

使用命令行参数运行程序：

```
python advanced_auto_install.py -d 目录路径 [选项]
```

例如：
```
python advanced_auto_install.py -d C:\Downloads -s --filter "chrome|firefox" --min-size 10
```

## 详细使用说明

### 图形界面模式

#### 主界面元素

1. **目录选择**
   - **根目录**：指定查找安装文件的根目录
   - **浏览**：打开文件浏览器选择目录
   - **刷新**：重新扫描目录并应用过滤条件

2. **过滤选项**
   - **名称过滤**：根据文件名过滤，支持正则表达式
   - **最小大小(MB)**：文件大小下限
   - **最大大小(MB)**：文件大小上限（0表示不限制）
   - **包含子文件夹**：是否在子文件夹中查找安装文件
   - **交互式安装**：是否使用交互模式而非静默安装
   - **超时时间(秒)**：安装程序的最大运行时间

3. **文件列表**
   - 显示符合条件的安装文件
   - 列出文件名、大小和安装状态
   - 可以选择多个文件进行安装

4. **操作按钮**
   - **全选/取消全选**：选择或取消选择所有文件
   - **安装选中项**：安装选中的文件
   - **查看日志**：打开最近的安装日志
   - **退出**：关闭程序

#### 操作步骤

1. **选择目录**：
   - 点击"浏览"按钮选择包含安装文件的根目录
   - 默认会在该目录下查找"exe"子文件夹

2. **设置过滤条件**：
   - 名称过滤：输入关键词或正则表达式过滤文件名
   - 大小过滤：设置文件大小范围
   - 其他选项：根据需要勾选"包含子文件夹"、"交互式安装"等

3. **查找文件**：
   - 点击"应用过滤"或"刷新"按钮查找符合条件的安装文件
   - 文件列表会显示找到的文件

4. **选择文件**：
   - 在文件列表中选择要安装的文件
   - 可以使用Ctrl或Shift键进行多选
   - 也可以使用"全选"按钮选择所有文件

5. **安装文件**：
   - 点击"安装选中项"按钮开始安装
   - 安装过程会在后台进行，界面不会冻结
   - 文件列表会实时更新安装状态

6. **查看结果**：
   - 安装完成后，文件列表会显示每个文件的安装结果
   - 成功安装的文件会标记为绿色
   - 安装失败的文件会标记为红色
   - 可以点击"查看日志"按钮查看详细日志

### 命令行模式

#### 可用参数

```
-d, --directory      指定根目录，默认为脚本所在目录
-s, --subfolders     是否包含子文件夹中的exe文件
-f, --filter         文件名过滤，支持正则表达式
--min-size           最小文件大小(MB)
--max-size           最大文件大小(MB)
-t, --timeout        安装超时时间(秒)，默认300秒
-i, --interactive    使用交互模式安装，而非静默安装
-h, --help           显示帮助信息
```

#### 使用示例

1. **基本使用**：
   ```
   python advanced_auto_install.py
   ```
   不带参数运行会启动图形界面模式。

2. **指定目录**：
   ```
   python advanced_auto_install.py -d C:\Downloads
   ```
   在指定目录的exe子文件夹中查找安装文件。

3. **包含子文件夹**：
   ```
   python advanced_auto_install.py -d C:\Downloads -s
   ```
   递归搜索子文件夹中的安装文件。

4. **过滤文件名**：
   ```
   python advanced_auto_install.py -f "chrome|firefox"
   ```
   只查找文件名包含"chrome"或"firefox"的安装文件。

5. **过滤文件大小**：
   ```
   python advanced_auto_install.py --min-size 10 --max-size 100
   ```
   只查找大小在10MB到100MB之间的安装文件。

6. **交互式安装**：
   ```
   python advanced_auto_install.py -i
   ```
   使用交互模式安装，而非尝试静默安装。

7. **组合使用**：
   ```
   python advanced_auto_install.py -d C:\Downloads -s -f "setup" --min-size 5 -t 600
   ```
   在C:\Downloads及其子文件夹中查找文件名包含"setup"且大小大于5MB的安装文件，安装超时时间设为600秒。

## 简化版程序

除了完整版的`advanced_auto_install.py`，还提供了简化版的`auto_install.py`，适合简单场景：

```
python auto_install.py
```

简化版只提供命令行界面，没有过滤条件，会直接安装`exe`目录下的所有exe文件。

## 日志系统

所有安装操作都会生成详细的日志，保存在`install_logs`目录下，文件名格式为：
```
install_log_YYYYMMDD_HHMMSS.txt
```

日志记录了每个安装文件的处理过程、使用的安装参数、安装结果等信息，便于排查问题。

## 静默安装参数

程序会自动尝试以下常见的静默安装参数：

- `/S` - 许多安装程序
- `/silent` - 一些安装程序
- `/quiet` - 微软安装程序
- `/verysilent` - Inno Setup
- `/passive` - MSI安装程序
- `--silent` - 一些安装程序
- `-s` - 一些安装程序
- `-q` - 一些安装程序
- `/q` - 微软安装程序
- `/AUTO` - 一些安装程序

对于特定的程序（如Python, Git, VC++运行库等），程序会使用专门的安装参数。

## 常见问题

### 1. 无法找到安装文件

**问题**：程序提示"未找到符合条件的exe文件"。

**解决方案**：
- 确认指定的根目录下有`exe`子文件夹
- 检查过滤条件是否过于严格
- 尝试勾选"包含子文件夹"选项
- 检查文件扩展名是否为.exe

### 2. 安装失败

**问题**：某些文件安装失败。

**解决方案**：
- 查看安装日志了解具体错误
- 尝试使用"交互式安装"模式
- 检查安装文件是否损坏
- 手动运行安装文件检查是否有特殊要求

### 3. 界面无响应

**问题**：点击"安装选中项"后界面无响应。

**解决方案**：
- 安装过程在后台线程进行，界面应该仍然可以操作
- 如果界面确实冻结，可能是因为某个安装程序的问题
- 尝试增加超时时间
- 重启程序并一次只安装少量文件

### 4. 命令行参数不起作用

**问题**：设置的命令行参数似乎没有效果。

**解决方案**：
- 检查参数格式是否正确
- 对于包含空格的路径，使用引号包围
- 确保正则表达式语法正确
- 使用`-h`参数查看帮助信息

## 安全注意事项

- 始终从可信来源获取安装文件
- 在运行批量安装前，建议先手动检查安装文件
- 注意某些安装程序可能需要管理员权限
- 建议在虚拟机或测试环境中测试批量安装
- 安装前备份重要数据
