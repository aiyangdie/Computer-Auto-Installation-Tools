# Quanshi_BAT合并系统 - 框架说明

## 系统架构

Quanshi是一个模块化设计的BAT文件合并系统，采用分层架构，主要包含以下几个层次：

1. **核心层**：实现基本的文件合并功能
2. **界面层**：提供命令行和图形界面两种交互方式
3. **启动层**：统一的入口点，引导用户选择合适的界面

## 核心组件

### 1. 核心模块 (quanshi.py)

核心模块负责实际的文件合并操作，主要功能包括：

- 文件搜索：查找指定目录下的所有BAT文件
- 文件读取：支持UTF-8和GBK编码
- 内容合并：将多个文件内容合并为一个文件
- 分隔标记：为每个文件添加清晰的分隔标记
- 备份功能：创建输出文件的备份

### 2. 图形界面模块 (quanshi_gui.py)

基于tkinter构建的图形界面，提供可视化操作：

- 文件选择：通过对话框选择要合并的文件
- 参数设置：配置合并选项
- 进度显示：显示合并进度
- 结果反馈：显示操作结果

### 3. 启动器模块 (quanshi_launcher.py)

系统的统一入口点，负责：

- 版本选择：引导用户选择命令行或图形界面版本
- 环境检查：检查必要的依赖是否满足
- 帮助文档：提供使用帮助

### 4. 示例模块 (merge_winget_bats.py)

展示如何使用Quanshi核心功能的示例脚本：

- 自动查找：查找所有winget相关的BAT文件
- 自动合并：调用核心模块进行合并
- 错误处理：处理可能的异常情况

## 数据流

1. 用户通过启动器选择操作模式
2. 界面层收集用户输入和参数
3. 调用核心层执行文件合并
4. 将结果反馈给用户

## 扩展性

系统设计考虑了良好的扩展性：

- 可以轻松添加新的界面类型
- 可以扩展核心模块支持更多文件类型
- 可以开发更多的示例脚本展示不同的使用场景

## 依赖关系

- Python 3.6+：基础运行环境
- tkinter：图形界面依赖库（Python标准库）
- 标准库：os, sys, argparse, shutil, datetime等
