# Quanshi GUI - BAT文件合并工具图形界面版

这是一个用于合并多个BAT批处理文件的图形界面工具。

## 功能特点

- 直观的图形用户界面，无需使用命令行
- 可视化选择要合并的BAT文件
- 轻松浏览和选择输入目录和输出文件
- 支持一键选择所有winget相关文件
- 为每个文件添加清晰的分隔标记
- 自动跳过重复的`@echo off`命令
- 支持UTF-8和GBK编码的BAT文件
- 可选择是否创建输出文件的备份
- 可选择是否添加文件分隔标记

## 使用方法

1. 运行程序:
   ```
   python quanshi_gui.py
   ```

2. 使用界面:
   - 选择包含BAT文件的输入目录
   - 指定合并后的输出文件
   - 在列表中选择要合并的文件(可使用Ctrl或Shift进行多选)
   - 设置选项(是否添加分隔标记、是否创建备份)
   - 点击"合并文件"按钮执行合并操作

## 界面说明

- **输入目录**: 指定要搜索BAT文件的目录
- **输出文件**: 指定合并后的文件名和路径
- **添加文件分隔标记**: 在合并文件中添加清晰的文件开始和结束标记
- **创建输出文件备份**: 如果输出文件已存在，创建备份
- **文件列表**: 显示所有可用的BAT文件，可多选
- **刷新列表**: 重新扫描目录获取BAT文件列表
- **全选/取消全选**: 选择或取消选择所有文件
- **选择以winget_开头的文件**: 自动选择所有winget相关文件
- **合并文件**: 执行文件合并操作

## 系统要求

- Python 3.6 或更高版本
- tkinter (Python标准库，通常随Python一起安装)

## 注意事项

- 如果文件无法以UTF-8编码读取，程序会尝试使用GBK编码
- 建议在合并重要文件前使用备份选项创建备份
