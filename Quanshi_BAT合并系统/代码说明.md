#### 1. `list_bat_files(directory='.')`

```python
def list_bat_files(directory='.'):
    """列出指定目录中的所有.bat文件"""
    bat_files = []
    for file in os.listdir(directory):
        if file.lower().endswith('.bat'):
            bat_files.append(os.path.join(directory, file))
    return bat_files
```

这个函数扫描指定目录，返回所有扩展名为.bat的文件列表。

#### 3. `backup_file(file_path)`

```python
def backup_file(file_path):
    """创建指定文件的备份"""
    if os.path.exists(file_path):
        backup_path = f"{file_path}.bak.{datetime.now().strftime('%Y%m%d%H%M%S')}"
        shutil.copy2(file_path, backup_path)
        print(f"Created backup: {backup_path}")
```

这个函数用于在覆盖现有文件前创建备份，备份文件名包含时间戳。
