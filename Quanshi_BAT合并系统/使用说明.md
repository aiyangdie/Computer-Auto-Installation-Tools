# Quanshi_BAT合并系统 - 使用说明

## 简介

Quanshi是一个用于合并多个BAT批处理文件的工具，它提供了命令行和图形界面两种使用方式，适合不同用户的需求。通过Quanshi，您可以轻松地将多个BAT文件合并为一个，同时保持良好的结构和可读性。

## 系统要求

- Python 3.6 或更高版本
- 图形界面版本需要 tkinter (Python标准库，通常随Python一起安装)
- Windows操作系统 (主要针对BAT文件)

## 快速开始

最简单的方法是使用启动器，它会引导您选择合适的版本：

```
start_quanshi.bat
```

或者直接使用Python运行启动器：

```
python quanshi_launcher.py
```

## 详细使用方法

### 1. 命令行版本

命令行版本适合熟悉命令行的用户，支持批处理和脚本化操作，可以通过参数精确控制合并行为。

#### 基本用法

```
python quanshi.py -o 输出文件名 -d 目录路径
```

#### 完整参数说明

```
python quanshi.py -h
```

输出：

```
usage: quanshi.py [-h] [-o OUTPUT] [-d DIRECTORY] [-f FILES [FILES ...]] [--no-headers] [--backup]

Merge multiple .bat files into a single file

optional arguments:
  -h, --help            显示帮助信息并退出
  -o OUTPUT, --output OUTPUT
                        输出文件名 (默认: merged.bat)
  -d DIRECTORY, --directory DIRECTORY
                        包含.bat文件的目录 (默认: 当前目录)
  -f FILES [FILES ...], --files FILES [FILES ...]
                        指定要合并的特定.bat文件
  --no-headers          不添加文件分隔标记
  --backup              如果输出文件已存在，创建备份
```

#### 示例

1. 合并当前目录下的所有BAT文件：

```
python quanshi.py -o combined.bat
```

2. 合并指定目录下的所有BAT文件：

```
python quanshi.py -o combined.bat -d C:\Scripts
```

3. 合并特定的几个BAT文件：

```
python quanshi.py -o combined.bat -f file1.bat file2.bat file3.bat
```

4. 合并文件并创建备份：

```
python quanshi.py -o combined.bat --backup
```

5. 合并文件但不添加分隔标记：

```
python quanshi.py -o combined.bat --no-headers
```

### 2. 图形界面版本

图形界面版本适合不熟悉命令行的用户，提供直观的文件选择和参数设置界面，可视化操作，易于使用。

#### 启动方式

```
python quanshi_gui.py
```

#### 操作步骤

1. 设置输出文件：点击"浏览"按钮选择输出文件名和位置
2. 选择要合并的文件：
   - 方式一：点击"选择目录"按钮选择包含BAT文件的目录
   - 方式二：点击"选择文件"按钮选择特定的BAT文件
3. 配置选项：
   - 勾选"添加文件分隔标记"以在合并文件中添加清晰的分隔标记
   - 勾选"创建备份"以在覆盖现有文件前创建备份
4. 点击"合并文件"按钮执行合并操作
5. 查看操作结果

### 3. 示例脚本

系统还提供了一个示例脚本，用于自动合并所有winget相关的BAT文件，展示了如何在其他脚本中使用quanshi.py。

#### 运行方式

```
python merge_winget_bats.py
```

#### 工作原理

1. 脚本会自动查找当前目录下所有以"winget_"开头的BAT文件
2. 调用quanshi.py将这些文件合并为一个名为"winget_all_in_one.bat"的文件
3. 自动创建备份（如果输出文件已存在）

## 注意事项

1. 合并后的BAT文件会自动跳过重复的`@echo off`命令
2. 如果文件无法以UTF-8编码读取，程序会尝试使用GBK编码
3. 建议在合并重要文件前使用备份选项创建备份
4. 合并大量文件可能会导致输出文件较大，请确保有足够的磁盘空间

## 常见问题

### Q: 为什么我无法启动图形界面版本？
A: 请确保您的Python安装包含tkinter库。在大多数Python安装中，tkinter是默认包含的。您可以通过运行`python -m tkinter`来检查tkinter是否可用。

### Q: 合并后的文件中为什么有些命令不能正常工作？
A: BAT文件中的某些命令可能依赖于特定的上下文或环境变量。合并后，这些命令可能需要调整以正确工作。

### Q: 如何在合并后的文件中找到特定的原始文件部分？
A: 如果您使用了文件分隔标记选项（默认开启），每个原始文件的内容都会被清晰的分隔标记包围，格式如下：
```
:==============================================================================
:: START OF filename.bat
:==============================================================================
[文件内容]
:==============================================================================
:: END OF filename.bat
:==============================================================================
```

### Q: 如何自动化合并过程？
A: 您可以创建一个批处理文件或Python脚本，调用quanshi.py并传递所需的参数。示例脚本merge_winget_bats.py展示了如何做到这一点。
