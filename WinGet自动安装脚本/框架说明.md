# WinGet自动安装脚本 - 框架说明

## 系统架构

WinGet自动安装脚本是一系列基于Windows Package Manager (WinGet)的批处理脚本集合，采用模块化设计，每个脚本负责特定的功能领域。

## 核心组件

### 1. 基础安装模块

#### winget_install.bat

预设软件列表安装脚本，包含常用软件的预定义列表，可一键安装所有预设软件。

主要功能：
- 环境检查：验证WinGet是否安装、管理员权限等
- 软件分类：按类别（系统工具、浏览器、开发工具等）组织软件
- 安装流程：批量安装所选软件
- 日志记录：详细记录安装过程和结果

#### winget_custom_install.bat

自定义软件列表安装脚本，从外部文件读取要安装的软件列表，支持用户自定义安装需求。

主要功能：
- 配置文件：读取/创建software_list.txt文件
- 解析配置：支持注释和说明
- 灵活安装：根据配置文件安装指定软件
- 结果统计：统计成功和失败的安装数量

### 2. 分类管理模块

#### winget_categories.bat

按分类安装软件的脚本，提供更细致的软件分类和管理。

主要功能：
- 分类目录：创建和管理软件分类目录
- 分类文件：为每个分类维护单独的软件列表
- 分类安装：按分类选择性安装软件
- 分类统计：统计每个分类的安装情况

### 3. 搜索与发现模块

#### winget_search.bat

软件搜索脚本，帮助用户查找可用的软件包。

主要功能：
- 关键词搜索：根据关键词查找软件
- 结果过滤：按名称、ID、版本等过滤结果
- 结果展示：格式化显示搜索结果
- 安装选项：可直接从搜索结果安装软件

### 4. 维护与更新模块

#### winget_update.bat

软件更新脚本，检查并更新已安装的软件。

主要功能：
- 更新检查：检查可更新的软件
- 选择性更新：可选择要更新的软件
- 批量更新：一键更新所有软件
- 更新日志：记录更新过程和结果

#### winget_repair.bat

WinGet修复脚本，解决常见的WinGet相关问题。

主要功能：
- 问题诊断：检测常见的WinGet问题
- 自动修复：尝试自动解决已知问题
- 手动指导：提供无法自动修复的问题的解决方案
- 环境验证：验证WinGet环境是否正常

### 5. 导入导出模块

#### winget_export_import.bat

软件列表导出导入脚本，用于备份和恢复软件环境。

主要功能：
- 导出列表：导出已安装软件的列表
- 导入列表：从导出文件安装软件
- 环境迁移：在不同电脑间迁移软件环境
- 版本控制：支持不同版本的导出格式

### 6. 报告与分析模块

#### winget_report.bat

生成软件安装报告的脚本，提供系统软件状态的概览。

主要功能：
- 安装统计：统计已安装的软件数量和类型
- 更新状态：检查软件的更新状态
- 健康检查：检查软件安装的完整性
- 报告生成：生成详细的系统软件报告

### 7. 综合控制模块

#### winget_master.bat

主控脚本，整合所有功能，提供统一的界面。

主要功能：
- 功能菜单：提供所有可用功能的菜单
- 参数传递：向子脚本传递参数
- 结果汇总：汇总各个子脚本的执行结果
- 用户引导：引导用户选择合适的功能

## 数据流

1. 用户通过主控脚本或直接调用特定脚本
2. 脚本执行环境检查和参数解析
3. 调用WinGet命令执行实际操作
4. 处理操作结果并生成日志
5. 向用户反馈执行结果

## 扩展性

系统设计考虑了良好的扩展性：

- 模块化设计：每个脚本专注于特定功能，易于维护和扩展
- 配置驱动：通过外部配置文件控制行为，无需修改脚本
- 日志系统：详细的日志记录便于调试和改进
- 参数化：支持通过参数自定义行为

## 依赖关系

- Windows 10 1709或更高版本
- Windows Package Manager (WinGet)
- 管理员权限（某些操作需要）
