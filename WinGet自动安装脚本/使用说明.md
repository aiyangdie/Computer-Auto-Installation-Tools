# WinGet自动安装脚本 - 使用说明

## 简介

WinGet自动安装脚本是一系列基于Windows Package Manager (WinGet)的批处理脚本，用于快速批量安装Windows软件。这套脚本集合提供了多种功能，包括预设软件安装、自定义软件安装、分类安装、搜索、更新、导入导出等，帮助用户高效管理Windows软件环境。

## 什么是WinGet？

WinGet是微软官方推出的命令行软件包管理工具，支持在Windows 10 1709及以上版本使用。它允许用户通过命令行快速地搜索、下载、安装、升级和卸载软件包，无需手动下载安装程序或访问各个软件的官方网站。

## 系统要求

- Windows 10 1709 或更高版本
- WinGet 已安装（Windows 10/11较新版本已预装）
- 推荐以管理员权限运行脚本

## 脚本列表及功能

### 1. 基础安装脚本 (winget_install.bat)

预设软件列表安装脚本，包含常用软件的预定义列表，可一键安装所有预设软件。

**使用方法：**

1. 右键点击`winget_install.bat`，选择"以管理员身份运行"
2. 脚本会显示将要安装的软件列表，按类别组织
3. 输入"Y"确认安装，或"N"取消
4. 安装过程会自动进行，并生成日志文件

**预设软件类别：**
- 系统工具：PowerToys, Windows Terminal, 7-Zip等
- 浏览器：Chrome, Firefox, Edge等
- 开发工具：Git, VS Code, Python等
- 通讯工具：WeChat, QQ, DingTalk等
- 其他工具：Bandizip, BaiduNetdisk等

### 2. 自定义安装脚本 (winget_custom_install.bat)

自定义软件列表安装脚本，从外部文件读取要安装的软件列表，支持用户自定义安装需求。

**使用方法：**

1. 首次运行时，脚本会创建`software_list.txt`示例文件
2. 编辑`software_list.txt`，根据需要添加或删除软件
   - 每行一个软件ID
   - 使用#开头的行为注释
   - 格式: `[软件ID] # [可选说明]`
3. 再次运行脚本进行安装
4. 输入"Y"确认安装，或"N"取消

**示例软件列表文件：**
```
# 软件列表文件 - 每行一个软件ID，井号开头的行为注释
# 格式: [软件ID] [可选说明]

# 系统工具
Microsoft.PowerToys                  # PowerToys
Microsoft.WindowsTerminal            # Windows Terminal

# 浏览器
Google.Chrome                        # Google Chrome
Mozilla.Firefox                      # Mozilla Firefox
```

### 3. 分类安装脚本 (winget_categories.bat)

按分类安装软件的脚本，提供更细致的软件分类和管理。

**使用方法：**

1. 运行`winget_categories.bat`
2. 首次运行时，脚本会创建示例分类文件在"软件分类"目录下
3. 从菜单中选择要安装的软件分类
4. 查看该分类中的软件列表，确认安装
5. 安装完成后可以选择继续安装其他分类或退出

**预设分类：**
- 开发工具：VS Code, Git, Python等
- 办公软件：Office, WPS, 腾讯会议等
- 系统工具：PowerToys, 7-Zip, Everything等
- 浏览器：Chrome, Firefox, Edge等
- 聊天通讯：WeChat, QQ, Telegram等
- 多媒体：VLC, PotPlayer, GIMP等

### 4. 搜索脚本 (winget_search.bat)

软件搜索脚本，帮助用户查找可用的软件包。

**使用方法：**

1. 运行`winget_search.bat`
2. 输入要搜索的软件名称或关键词
3. 查看搜索结果
4. 选择是否直接安装搜索结果中的软件
5. 如果选择安装，输入软件的ID进行安装

### 5. 更新脚本 (winget_update.bat)

软件更新脚本，检查并更新已安装的软件。

**使用方法：**

1. 运行`winget_update.bat`
2. 脚本会检查可更新的软件并显示列表
3. 选择更新选项：
   - 更新所有软件
   - 更新特定软件（需要输入软件ID）
   - 返回主菜单

### 6. 导出导入脚本 (winget_export_import.bat)

软件列表导出导入脚本，用于备份和恢复软件环境。

**使用方法：**

1. 运行`winget_export_import.bat`
2. 选择操作类型：导出或导入
3. 导出选项：
   - 导出所有已安装的软件
   - 导出所有已安装的应用程序
4. 导入选项：
   - 输入要导入的JSON文件路径
   - 确认导入

### 7. 修复脚本 (winget_repair.bat)

WinGet修复脚本，解决常见的WinGet相关问题。

**使用方法：**

1. 运行`winget_repair.bat`
2. 脚本会检测常见的WinGet问题
3. 选择要执行的修复操作
4. 按照提示完成修复过程

### 8. 报告脚本 (winget_report.bat)

生成软件安装报告的脚本，提供系统软件状态的概览。

**使用方法：**

1. 运行`winget_report.bat`
2. 选择要生成的报告类型
3. 查看生成的报告内容
4. 选择是否保存报告到文件

### 9. 主控脚本 (winget_master.bat)

主控脚本，整合所有功能，提供统一的界面。

**使用方法：**

1. 运行`winget_master.bat`
2. 从主菜单中选择要执行的功能
3. 按照选择的功能进入相应的子菜单
4. 完成操作后可以返回主菜单或退出

## 查找软件ID

要查找软件的ID，可以：

1. 使用命令：`winget search [软件名称]`
2. 使用脚本：`winget_search.bat`
3. 访问网站：[winget.run](https://winget.run/) 或 [winstall.app](https://winstall.app/)
4. 参考 [Microsoft 应用程序目录](https://learn.microsoft.com/zh-cn/windows/package-manager/package/)

## 常用WinGet命令

```
winget search [关键词]    # 搜索软件
winget install [ID]      # 安装软件
winget uninstall [ID]    # 卸载软件
winget upgrade           # 检查可更新的软件
winget upgrade --all     # 更新所有软件
winget list              # 列出已安装的软件
winget show [ID]         # 显示软件详情
```

## 常见问题

### 1. 未找到WinGet命令
- 确保你的Windows版本支持WinGet（Windows 10 1709或更高版本）
- 尝试运行：`Add-AppxPackage -RegisterByFamilyName -MainPackage Microsoft.DesktopAppInstaller_8wekyb3d8bbwe`
- 或使用`winget_repair.bat`脚本尝试修复

### 2. 安装失败
- 检查是否以管理员身份运行脚本
- 查看日志文件了解详细错误信息
- 确认网络连接正常
- 确保软件ID正确

### 3. 软件ID错误
- 使用`winget search`命令确认正确的软件ID
- 软件ID区分大小写，请确保输入准确

### 4. 批量安装时部分软件失败
- 查看日志文件了解具体哪些软件安装失败
- 尝试单独安装失败的软件
- 检查是否有特殊的安装要求或依赖项

## 自定义开发

如果你想修改脚本，可以：
- 在`winget_install.bat`中修改预设软件列表
- 调整安装参数以适应特定需求
- 添加额外的错误处理或功能
- 创建新的分类或整合其他功能

## 日志文件

所有脚本操作都会生成详细的日志文件，格式为：
```
winget_*_log_YYYYMMDD_HHMMSS.txt
```

日志文件包含：
- 操作时间戳
- 执行的命令
- 安装/更新结果
- 错误信息（如果有）

## 安全注意事项

- 始终从可信来源获取软件
- 定期更新WinGet以获取最新的安全修复
- 检查软件的安装参数和权限
- 在运行脚本前检查其内容，确保安全
