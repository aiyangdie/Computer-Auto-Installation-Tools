# WinGet自动安装脚本 - 代码说明

## 批处理脚本基础结构

WinGet自动安装脚本系列采用Windows批处理脚本(.bat)编写，每个脚本都遵循类似的基础结构：

```batch
@echo off
setlocal enabledelayedexpansion

:: 脚本标题
echo ===================================================
echo     脚本名称和功能描述
echo ===================================================
echo.

:: 环境检查
where winget >nul 2>nul
if %ERRORLEVEL% NEQ 0 (
    echo WinGet未找到，提供解决方案...
    goto :EOF
)

:: 管理员权限检查
net session >nul 2>&1
if %ERRORLEVEL% NEQ 0 (
    echo 警告: 未以管理员身份运行...
)

:: 日志文件设置
set "logfile=%~dp0winget_log_%date:~0,4%%date:~5,2%%date:~8,2%_%time:~0,2%%time:~3,2%%time:~6,2%.txt"
set "logfile=%logfile: =0%"

:: 主要功能代码...

:: 结束脚本
echo 操作完成！
pause
goto :EOF

:: 函数定义
:function_name
    :: 函数代码
    goto :EOF
```

## 主要脚本代码解析

### 1. winget_install.bat

这个脚本包含预定义的软件列表，用于批量安装常用软件。

#### 关键代码段

```batch
:: 软件列表定义
echo 系统工具:
echo - Microsoft.PowerToys
echo - Microsoft.WindowsTerminal
echo - 7zip.7zip
...

:: 安装函数
:install_app
set "app_id=%~1"
set "app_name=%~2"
echo 正在安装 %app_name%...
echo [%date% %time%] 正在安装 %app_name% (%app_id%)... >> "%logfile%"
winget install --id %app_id% --accept-source-agreements --accept-package-agreements >> "%logfile%" 2>&1
if %ERRORLEVEL% EQU 0 (
    echo [成功] %app_name% 安装完成
    echo [%date% %time%] [成功] %app_name% 安装完成 >> "%logfile%"
) else (
    echo [失败] %app_name% 安装失败，错误代码: %ERRORLEVEL%
    echo [%date% %time%] [失败] %app_name% 安装失败，错误代码: %ERRORLEVEL% >> "%logfile%"
)
echo. >> "%logfile%"
echo.
goto :EOF
```

这段代码展示了如何定义软件列表和创建安装函数。安装函数接受软件ID和名称作为参数，调用WinGet进行安装，并记录结果到日志文件。

### 2. winget_custom_install.bat

这个脚本从外部文件读取软件列表，支持用户自定义安装需求。

#### 关键代码段

```batch
:: 检查软件列表文件是否存在
set "software_list_file=%~dp0software_list.txt"
if not exist "%software_list_file%" (
    echo 未找到软件列表文件，创建示例文件...
    (
        echo # 软件列表文件 - 每行一个软件ID，井号开头的行为注释
        echo # 格式: [软件ID] [可选说明]
        echo.
        echo # 系统工具
        echo Microsoft.PowerToys                  # PowerToys
        ...
    ) > "%software_list_file%"
    echo 已创建示例软件列表文件: %software_list_file%
    pause
    goto :EOF
)

:: 读取软件列表
set "app_count=0"
for /f "tokens=1* delims= " %%a in ('type "%software_list_file%" ^| findstr /v "^#" ^| findstr /v "^$"') do (
    set /a "app_count+=1"
    set "app_id[!app_count!]=%%a"
    
    :: 尝试提取注释作为应用名称
    set "app_name[!app_count!]=%%a"
    if "%%b" NEQ "" (
        set "comment=%%b"
        if "!comment:~0,1!" == "#" (
            set "app_name[!app_count!]=!comment:~1!"
            set "app_name[!app_count!]=!app_name[!app_count!]:~1!"
        )
    )
    
    echo !app_count!. !app_id[!app_count!]! - !app_name[!app_count!]!
)
```

这段代码展示了如何读取和解析外部软件列表文件，支持注释和说明，并提取软件ID和名称。

### 3. winget_categories.bat

这个脚本按分类安装软件，提供更细致的软件分类和管理。

#### 关键代码段

```batch
:: 创建分类目录
set "categories_dir=%~dp0软件分类"
if not exist "%categories_dir%" mkdir "%categories_dir%"

:: 检查分类文件
if not exist "%categories_dir%\开发工具.txt" (
    echo 未找到分类文件，正在创建示例分类...
    
    :: 创建开发工具分类
    (
        echo # 开发工具列表
        echo Microsoft.VisualStudioCode      # VS Code
        echo Git.Git                         # Git版本控制
        ...
    ) > "%categories_dir%\开发工具.txt"
    
    :: 创建其他分类...
)

:: 显示分类菜单
echo 请选择要安装的软件分类:
set "category_count=0"
for %%f in ("%categories_dir%\*.txt") do (
    set /a "category_count+=1"
    set "category_file[!category_count!]=%%f"
    set "category_name[!category_count!]=%%~nf"
    echo !category_count!. %%~nf
)
```

这段代码展示了如何创建和管理软件分类目录，以及如何显示分类菜单供用户选择。

### 4. winget_search.bat

这个脚本用于搜索可用的软件包。

#### 关键代码段

```batch
:: 获取搜索关键词
set "search_term="
echo 请输入要搜索的软件名称或关键词:
set /p search_term="> "

if "%search_term%"=="" (
    echo 搜索关键词不能为空！
    goto :search_again
)

:: 执行搜索
echo.
echo 正在搜索 "%search_term%" ...
echo.
winget search "%search_term%" --accept-source-agreements

:: 安装选项
echo.
echo 是否要安装搜索结果中的软件？
echo 1. 是，通过ID安装
echo 2. 否，返回主菜单
echo.
choice /c 12 /n /m "请选择 [1-2]: "
```

这段代码展示了如何获取用户输入的搜索关键词，调用WinGet执行搜索，并提供安装选项。

### 5. winget_update.bat

这个脚本用于检查并更新已安装的软件。

#### 关键代码段

```batch
:: 检查可更新的软件
echo 正在检查可更新的软件...
echo.
winget upgrade --accept-source-agreements

:: 更新选项
echo.
echo 请选择更新选项:
echo 1. 更新所有软件
echo 2. 更新特定软件
echo 3. 返回主菜单
echo.
choice /c 123 /n /m "请选择 [1-3]: "

if %ERRORLEVEL% EQU 1 (
    :: 更新所有软件
    echo.
    echo 正在更新所有软件...
    echo.
    winget upgrade --all --accept-source-agreements --accept-package-agreements
) else if %ERRORLEVEL% EQU 2 (
    :: 更新特定软件
    echo.
    set "app_id="
    echo 请输入要更新的软件ID:
    set /p app_id="> "
    
    if "%app_id%"=="" (
        echo 软件ID不能为空！
        goto :update_options
    )
    
    echo.
    echo 正在更新 %app_id% ...
    echo.
    winget upgrade --id %app_id% --accept-source-agreements --accept-package-agreements
)
```

这段代码展示了如何检查可更新的软件，并提供全部更新或选择性更新的选项。

### 6. winget_export_import.bat

这个脚本用于导出和导入软件列表。

#### 关键代码段

```batch
:: 导出选项
:export_menu
echo.
echo 导出选项:
echo 1. 导出所有已安装的软件
echo 2. 导出所有已安装的应用程序
echo 3. 返回主菜单
echo.
choice /c 123 /n /m "请选择 [1-3]: "

if %ERRORLEVEL% EQU 1 (
    :: 导出所有软件
    set "export_file=%~dp0winget_export_%date:~0,4%%date:~5,2%%date:~8,2%.json"
    echo.
    echo 正在导出所有已安装的软件到 %export_file% ...
    echo.
    winget export -o "%export_file%" --accept-source-agreements
) else if %ERRORLEVEL% EQU 2 (
    :: 导出应用程序
    set "export_file=%~dp0winget_export_apps_%date:~0,4%%date:~5,2%%date:~8,2%.json"
    echo.
    echo 正在导出所有已安装的应用程序到 %export_file% ...
    echo.
    winget export -o "%export_file%" --include-programs --accept-source-agreements
)

:: 导入选项
:import_menu
echo.
echo 请选择要导入的JSON文件:
echo.
set "import_file="
set /p import_file="文件路径: "

if "%import_file%"=="" (
    echo 文件路径不能为空！
    goto :import_menu
)

if not exist "%import_file%" (
    echo 文件不存在: %import_file%
    goto :import_menu
)

echo.
echo 正在从 %import_file% 导入软件...
echo.
winget import -i "%import_file%" --accept-source-agreements --accept-package-agreements
```

这段代码展示了如何导出已安装的软件列表到JSON文件，以及如何从JSON文件导入软件。

## 批处理脚本技术特点

### 1. 变量和环境

```batch
:: 使用setlocal启用本地变量环境
setlocal enabledelayedexpansion

:: 使用!variable!语法访问动态变量值
set "count=0"
for %%i in (1 2 3) do (
    set /a "count+=1"
    echo !count!. %%i
)
```

### 2. 错误处理

```batch
:: 检查命令执行结果
command
if %ERRORLEVEL% NEQ 0 (
    echo 命令执行失败，错误代码: %ERRORLEVEL%
    goto :error_handler
)

:: 重定向错误输出
command > output.txt 2> error.txt

:: 同时重定向标准输出和错误输出
command > output.txt 2>&1
```

### 3. 函数和子程序

```batch
:: 定义函数
:function_name
    :: 函数代码
    goto :EOF

:: 调用函数
call :function_name param1 param2

:: 在函数中访问参数
:function_name
    echo 第一个参数: %~1
    echo 第二个参数: %~2
    goto :EOF
```

### 4. 用户交互

```batch
:: 提示用户输入
set "input="
set /p input="请输入: "

:: 选择菜单
choice /c YN /m "是否继续？(Y/N)"
if %ERRORLEVEL% EQU 1 (
    echo 用户选择了Y
) else (
    echo 用户选择了N
)
```

### 5. 文件和目录操作

```batch
:: 检查文件是否存在
if exist "filename.txt" (
    echo 文件存在
)

:: 创建目录
if not exist "directory" mkdir "directory"

:: 遍历文件
for %%f in (*.txt) do (
    echo 处理文件: %%f
)
```

3. **错误处理**：包含适当的错误检查和处理机制
